# Train Manager (рабочее название)

Мобильная 2D-игра про логистику поездов в духе Pocket Trains, расширенная новыми механиками.
Unity **6000.3.12f1 (6.3 LTS)**, URP 2D, C#, Unity UI + TextMeshPro, новый Input System.

## Структура

```
Assets/
├── Scripts/
│   ├── Data/     Конфиги (ScriptableObject): RegionData, CityData, RailwayLineData, RouteData,
│   │             TrainData и GameDatabase — каталог всех конфигов с поиском по ID
│   ├── Core/     Фундамент: GameRoot (точка входа), GameState (прогресс игрока),
│   │             TrainInstance (поезд игрока), TrainService (правила движения),
│   │             SaveService (сохранение), GameClock (реальное время), GameEvents (события)
│   ├── Trains/   TrainState, TrainView (картинка поезда)
│   ├── Map/      MapView, StationView, MapNavigator (перетаскивание и масштаб)
│   ├── UI/       RoutePlanner (маршрут нажатием на города), TrainStatusText, RouteButton
│   └── Editor/   MapDataImporter (карта из текста), ParisPrototypeBuilder (сцена)
├── Data/
│   ├── MapSource/*.txt   ← карта мира: по файлу на континент + _World.txt. Правится руками
│   └── остальное создаётся импортом/сборщиком: регион, города, линии, поезд, GameDatabase
└── Scenes/       создаётся сборщиком: ParisPrototype.unity
```

## Правила архитектуры

- Все `.cs` в UTF-8 (см. `.editorconfig`).
- **Конфиги** (ScriptableObject) — неизменяемые шаблоны. **Прогресс игрока** — только в `GameState`.
- В `GameState` хранятся **строковые ID** конфигов, а не ссылки на ассеты. По ID конфиг находит `GameDatabase`.
  Новый конфиг нужно добавить в список `GameDatabase`.
- Логика — в обычных C#-сервисах (`TrainService`), не в MonoBehaviour. Картинка только показывает.
- Время — только из `IGameClock` (реальное время), не из `Time.deltaTime`. Поездки идут, даже когда игра закрыта.
- **Линия** (участок между двумя городами) и **маршрут** (цепочка городов у поезда) — разные вещи.
  Дистанция маршрута складывается из линий.
- Никакой случайности в базовой логике.

## Карта

Карта мира задаётся текстовыми файлами в `Assets/Data/MapSource/` (формат описан в `_World.txt`):
- `Europe.txt`, `Asia.txt`, `Africa.txt`, `NorthAmerica.txt`, `SouthAmerica.txt`, `Oceania.txt` — регион,
  ключевые города (реальные широта и долгота) и линии внутри региона;
- `_World.txt` — проекция карты и межконтинентальные линии (Гибралтар, Атлантика, Панама и т. п.).

Сеть своя: линии проведены по географии (соседние города, сухопутные коридоры, несколько морских переправ).
- Позиция города считается из координат (проекция Меркатора).
- Дистанция линии = расстояние по прямой в км, округлённое до 10 (можно задать вручную).
- После правки файлов: **Tools → Train Manager → Import Map Data** (или пересобрать сцену).

## Как проверить

1. Открой проект в Unity Hub и дождись, пока Unity закончит компиляцию (внизу справа пропадёт крутилка).
2. В верхнем меню: **Tools → Train Manager → Build Paris Prototype Scene**.
3. Нажми **Play**.

Что должно быть:
- Карта мира: 210 городов, 311 линий. Поезд (красный прямоугольник) стоит в Париже, карта отцентрована на нём.
- Карту можно таскать мышью/пальцем, колесо мыши или щипок — масштаб.
- Нажимай на зелёные (соседние) города — собирается маршрут, внизу видно дистанцию и время.
  Повторное нажатие на последний город убирает его. **Отправить** — в путь, **Сбросить** — заново.
- Пример: Париж → Брюссель → Амстердам → Берлин. Промежуточные города поезд проезжает без остановки,
  в Console пишется «проехал остановку …».
- **Сохранение:** останови Play, пока поезд едет, подожди и снова нажми Play. Поезд будет там,
  куда успел доехать за это время.
- Начать заново: **Tools → Train Manager → Delete Save**.
- В Console пишутся сообщения с префиксами `[Train]`, `[Game]`, `[Save]`, `[Map Import]`.
